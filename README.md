# Hollow Knight + Silksong Boss Playthrough Randomizer

Tired of fighting Gruz Mother and False Knight first? Now you don't have to!

This web app lets you randomize every boss in Hollow Knight and Silksong in an order you can attempt to follow in a playthrough!

## Features:

* Generate a random order of bosses to fight in either Hollow Knight or Silksong. (Boss orders should be possible without glitches)
* Enable skips that'll make some bosses even earlier than intended, such as acid skips to fight Uumuu before Dung Defender.
* Check off bosses you beat for easy tracking, which is stored even after you reload the page!

## Bugs and Suggestions

If you find an impossible boss order, report it as an issue describing why it's impossible, but be sure that the order is impossible and not simply a result of player error.
If there are more skips available, feel free to suggest any that have a relevant effect on the order!
